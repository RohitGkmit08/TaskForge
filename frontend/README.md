# TaskForge - Frontend

Client-side monitoring dashboard for TaskForge to monitor background jobs, inspect queues, view metrics, and manage task lifecycles.

## Features (Planned)
- Real-time job status monitoring (Waiting, Active, Completed, Failed, Delayed)
- Queue throughput and execution latency metrics
- Manual retry, pause, and cancellation controls
- Job payload inspector & error trace viewer
